# tinvest — скилл Claude Code для счетов в Т-Инвестициях

Четыре отчёта по твоим счетам: аудит (риски + честная доходность), календарь выплат и оферт,
налоги (ЛДВ, сальдирование, НДФЛ), план размещения взноса. Только чтение: ничего не покупает и не продаёт.

Принцип: модель собирает данные и объясняет, деньги считает код. Скрипты ходят в T-Invest API напрямую,
сырые ответы лежат в `~/.tinvest/data/`, расчёты повторяемы. T-Invest MCP — для диалога (новости, инсайдеры,
поиск бумаг, стакан), не для арифметики.

## Установка (10 минут)

1. **Положи папку скилла** в `~/.claude/skills/tinvest` (Windows: `%USERPROFILE%\.claude\skills\tinvest`).
2. **Окружение:** из папки скилла `bash setup.sh` (macOS/Linux) или `powershell -ExecutionPolicy Bypass -File setup.ps1` (Windows).
   Создаст `~/.tinvest/venv`, `~/.tinvest/.env`, `~/.tinvest/targets.yaml`.
3. **Токен.** В приложении/на сайте Т-Инвестиций: Настройки → Токены API → создать токен с доступом **«только чтение»**
   к нужным счетам (документация: developer.tbank.ru/invest/intro/intro/token). Положи его в переменную окружения
   пользователя `T_INVEST_IIS_READ` (Windows: «Изменить переменные среды пользователя»), токен песочницы — в `T_INVEST_SANDBOX`.
   Альтернатива — `~/.tinvest/.env` (`TINVEST_TOKEN`, `TINVEST_SANDBOX_TOKEN`). Скрипты проверяют оба места.
4. **Сертификаты Минцифры.** Если они уже установлены в Windows/macOS (сайты банков открываются без предупреждений),
   ничего делать не нужно: пакет `truststore` заставляет Python доверять системному хранилищу. Если API падает с ошибкой TLS, скачай с gosuslugi.ru/crt файлы
   `Russian_Trusted_Root_CA.cer` и `Russian_Trusted_Sub_CA.cer`, затем
   `python scripts/make_ca_bundle.py ~/Downloads/Russian_Trusted_Root_CA.cer ~/Downloads/Russian_Trusted_Sub_CA.cer`
   и впиши путь в `.env` как `TINVEST_CA_BUNDLE`. Тот же файл подойдёт для Claude Code: `NODE_EXTRA_CA_CERTS=~/.tinvest/ca-bundle.pem`.
5. **Проверка:** `~/.tinvest/venv/bin/python scripts/report.py check` — должен показать счета и уровень доступа.
6. **Первый отчёт:** `~/.tinvest/venv/bin/python scripts/report.py audit` (первая выгрузка занимает 1–3 минуты: история операций с открытия счёта).
7. В Claude Code: `/tinvest audit`, `/tinvest events`, `/tinvest tax`, `/tinvest deploy 400000` или просто «покажи аудит портфеля».
   MCP-серверы для Claude Code — `claude-code.mcp.example.json`: сохрани как `.mcp.json` в папке проекта, токены подставятся из переменных.

Песочница (ступень 3) через REST: `scripts/sandbox.py accounts | open | payin <id> <сумма> | close <id>` — использует только `T_INVEST_SANDBOX`.

Тесты математики на синтетических данных: `~/.tinvest/venv/bin/python tests/test_calc.py`.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `~/.tinvest/.env` | токены и настройки (не коммить, не пересылать) |
| `~/.tinvest/targets.yaml` | целевые доли для `deploy` |
| `~/.tinvest/fx.yaml` | ручные курсы валют, если API не дал (`usd: 84.0`) |
| `~/.tinvest/data/` | сырые ответы API: `accounts.json`, `<счёт>/portfolio.json`, `operations.json`, `cache/instruments.json`… |
| `~/.tinvest/reports/` | последние отчёты в markdown |
| `~/.tinvest/data-sandbox/` | то же для песочницы (`--sandbox`) |

## Команды

```
report.py check                 токен и счета
report.py audit  [--refresh]    риски + XIRR и бенчмарки + облигации + календарь 60 дней
report.py events [--days 60]    оферты, погашения, купоны, дивотсечки
report.py tax                   FIFO-лоты, ЛДВ, убытки под сальдирование, оценка НДФЛ
report.py deploy 400000         план покупок в лотах под targets.yaml, без продаж
report.py all                   audit + tax по всем счетам
fetch.py [--sandbox] [--targets ~/.tinvest/targets.yaml]   выгрузка данных
```

Данные обновляются сами, если выгрузке больше 12 часов; `--refresh` обновляет принудительно.

## Что считается и как

- **XIRR** — по внешним потокам: пополнения, выводы, переводы между счетами, покупки с карты; дивиденды, купоны,
  комиссии и налоги — внутренние (они уже в стоимости счёта). База 365 дней, как XIRR в Excel.
- **Бенчмарки** — те же суммы в те же даты в фонд денежного рынка (LQDT) и фонд на индекс (SBMX); взносы раньше
  первой свечи фонда условно лежат без дохода.
- **Оценка позиций** — `quantity × currentPrice` (+ НКД для облигаций); режим цены облигаций (рубли или % от номинала)
  выбирается автоматически по сверке с `totalAmountBonds` брокера.
- **YTM и дюрация** — по будущим купонам из API и номиналу к погашению; флоатеры — без YTM, амортизируемые — приближённо.
- **Налоги** — FIFO по операциям покупки/продажи с комиссиями; ЛДВ — 3 года, 3 млн ₽ за год владения; НДФЛ 13% до 2,4 млн, 15% выше.
  Это оценка, а не расчёт брокера: нет валютной переоценки, корпоративных действий, сальдирования с ПФИ.
- **deploy** — сначала закрывает дефициты групп до целевых долей, потом бумаг внутри групп, затем округляет до лотов и
  докупает остаток туда, где недобор больше.

## Ограничения

- Только чтение. Торговые и переводные права токена скриптам не нужны и не используются.
- Данные, которые Claude Code читает из отчётов, уходят в API модели как контекст разговора. Токены — нет.
- Формат ответов API может меняться; при расхождениях пришли `~/.tinvest/data/<счёт>/portfolio.json` (в нём нет токена).
