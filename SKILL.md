# tinvest — портфель Т-Инвестиций в Claude Code

Аргументы вызова: `$ARGUMENTS`

## Что это

Четыре отчёта по счетам пользователя в Т-Инвестициях. Данные скрипты берут из T-Invest API напрямую
(токен только-чтение), складывают в `~/.tinvest/data/` и считают всё детерминированно. Твоя роль —
запустить нужный скрипт, прочитать отчёт и объяснить его человеку: что важно, что требует действия, что в норме.

Папка скилла — та, где лежит этот файл (обычно `~/.claude/skills/tinvest`). Все команды ниже запускаются из неё.
Python — из окружения `~/.tinvest/venv` (создаётся при установке, см. README.md):

- macOS / Linux: `~/.tinvest/venv/bin/python scripts/report.py <команда>`
- Windows: `%USERPROFILE%\.tinvest\venv\Scripts\python.exe scripts\report.py <команда>`

Если venv нет — `python3 scripts/report.py` с установленными `requests pyyaml certifi`.

## Команды

| Команда | Что делает | Когда использовать |
| --- | --- | --- |
| `report.py check` | Проверяет токен, показывает счета и уровень доступа | первый запуск, «не работает» |
| `report.py audit` | Карта рисков + честная доходность (XIRR и сравнение с LQDT/индексом) + облигации + календарь на 60 дней | «как дела с портфелем», «аудит», «обгоняю ли я депозит» |
| `report.py events [--days N]` | Оферты, погашения, купоны, дивотсечки | «что по выплатам», «есть ли оферты» |
| `report.py tax` | FIFO-лоты, ЛДВ, убытки под сальдирование, оценка НДФЛ | «налоги», «что продать до конца года», «когда ЛДВ» |
| `report.py deploy <сумма>` | План покупок в лотах под целевые доли из `~/.tinvest/targets.yaml`, без продаж | «пришли деньги / взнос на ИИС, что купить» |
| `report.py all` | audit + tax по всем счетам | полный разбор |
| `fetch.py [--sandbox] [--targets ~/.tinvest/targets.yaml]` | Выгрузка данных (отчёты сами её обновляют, если ей больше 12 ч) | после изменений в портфеле, `--refresh` |

Флаги: `--refresh` принудительно обновить данные; `--account <id>` один счёт; `--sandbox` — песочница (другой токен и папка данных).

## Как вести разговор

1. Пойми, какая команда нужна. Если пользователь просто написал `/tinvest` без аргументов — запусти `audit`.
2. Запусти скрипт через Bash. Он печатает markdown и сохраняет копию в `~/.tinvest/reports/<команда>.md`.
3. Прочитай отчёт целиком и ответь по-человечески, на русском: сначала главное (2–4 предложения), потом детали.
   Что считать главным:
   - audit: расхождение с итогами брокера > 2% (данные не сходятся — скажи об этом первым); эмитент > 25%; топ-5 > 70%;
     валюта вне рубля без курса; дюрация облигаций > 5 (чувствительность к ставке); XIRR ниже строки LQDT — значит
     портфель проиграл фонду денежного рынка, скажи это прямо.
   - events: оферта в ближайшие 30 дней — всегда первой строкой, с датой и что делать; дивотсечки с последним днём покупки.
   - tax: прибыль года и оценка НДФЛ; убыточные лоты, которыми можно уменьшить базу; лоты, у которых ЛДВ через < 90 дней
     (не продавать до даты). Для ИИС — напомни, что налог отложен, и не предлагай сальдирование.
   - deploy: таблица покупок как есть + сколько осталось деньгами. Это план, не заявки.
4. Цифры — только из отчёта. Не округляй в уме, не досчитывай «примерно», не придумывай цены. Если нужного числа нет — так и скажи.
5. Заявки не выставляй и не предлагай выставить «автоматически». Любая сделка — решение пользователя, руками или на ступени 3 с подтверждением.
6. Отчёты покрывают цифры. Для всего остального — новости по бумаге, сделки инсайдеров, стакан, поиск бумаги, прогнозы —
   используй T-Invest MCP, если он подключён (`/mcp`). Когда отвечаешь по данным MCP, скажи, что это данные MCP.
7. Не печатай и не проси токен в чат. Токены живут в переменных окружения `T_INVEST_IIS_READ` / `T_INVEST_SANDBOX` или в `~/.tinvest/.env`; никогда не выводи их значения (даже `echo`/`env`).
8. Если данные приходят из T-Invest MCP (Claude Desktop), а не из fetch.py: сохрани ответы в `raw/`, заполни `mcp_extra.json` и запусти `scripts/mcp_ingest.py <папка>` — дальше те же отчёты.

## Если что-то сломалось

| Симптом | Что делать |
| --- | --- |
| `Нет токена` | Нет переменной `T_INVEST_IIS_READ` (или `TINVEST_TOKEN` в `~/.tinvest/.env`) — покажи README.md, раздел «Токены» |
| `Ошибка TLS` / `CERTIFICATE_VERIFY_FAILED` | Нужен CA-бандл с сертификатами Минцифры: `scripts/make_ca_bundle.py <файлы .cer>`, затем `TINVEST_CA_BUNDLE` в `.env` |
| `HTTP 401/403` | Токен без прав на счёт или истёк — выпустить новый (только чтение) |
| `HTTP 429` | Лимит запросов — подожди минуту, повтори с `--refresh` |
| Расхождение с брокером > 2% | Курсы валют (`~/.tinvest/fx.yaml`: `usd: 84.0`) или цена облигаций; покажи таблицу сверки пользователю |
| Поле не найдено / пустые таблицы | Формат API изменился. Попроси пользователя прислать `~/.tinvest/data/<счёт>/portfolio.json` (без токена) — это сырой ответ API |
| `Нет цены для <тикер>` в deploy | `fetch.py --targets ~/.tinvest/targets.yaml` |

Не чини скрипты молча на лету: если нужно править код, скажи что и почему, и правь в папке скилла.

## Файлы

- `scripts/report.py` — точка входа, оркестрирует остальное.
- `scripts/fetch.py` — выгрузка из API (счета, портфель, операции, справочник, купоны, события, дивиденды, курсы, бенчмарки).
- `scripts/tinvest_api.py` — REST-клиент. `scripts/model.py` — чтение выгрузки, оценка позиций в ₽, внешние потоки, сделки для FIFO.
- `scripts/finmath.py` — XIRR, YTM, дюрация, FIFO, размещение по долям (покрыто `tests/test_calc.py`).
- `scripts/audit.py`, `perf.py`, `bonds.py`, `events.py`, `tax.py`, `deploy.py` — отчёты.
- `scripts/make_ca_bundle.py` — CA-бандл с сертификатами Минцифры. `scripts/sandbox.py` — виртуальные счета песочницы (REST). `scripts/backtest.py [--fund TMOS|SBMX] [--refresh]` — бэктест тренд-фильтра IMOEX/SMA → фонд на индекс / LQDT с комиссиями, проскальзыванием, налогом и walk-forward (отчёт `~/.tinvest/reports/backtest_trend.md`). `scripts/mcp_ingest.py` — сборка данных из ответов MCP.
- `scripts/research.py fetch|train|holdout|all` — конвейер проверки стратегий на дневных свечах ~30 акций: `bt_data.py` (серии, сплиты, дивиденды, синтетический LQDT до 2020), `bt_sim.py` (портфельный симулятор), `bt_strategies.py` (momentum, donchian, trend_vol, div_runup, контроль), `bt_protocol.py` (окна TRAIN/VALID/HOLDOUT, отбор по плато, deflated Sharpe, журнал закрытого окна). Отчёты `~/.tinvest/reports/research_train.md`, `research_holdout.md`.
- `targets.example.yaml` → `~/.tinvest/targets.yaml` — целевые доли для deploy. `.env.example` → `~/.tinvest/.env`.
